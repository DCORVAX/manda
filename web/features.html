Features

Fast by default. Yours to configure.

Every default is chosen for practical day-one use, while staying 100% compatible with WezTerm’s Lua configuration — bring your existing config with zero migration.

01

Zero Config

JetBrains Mono, tuned macOS font rendering, and low-res font sizing out of the box. Open it and go.

02

Theme-Aware Experience

Auto-switches between dark and light modes with macOS, with tuned selection colors, font weight, and practical color overrides.

03

Curated Shell Suite

Built-in zsh plugins with optional CLI tools for prompt, diff, and navigation workflows — set up on first launch.

04

Fast & Lightweight

40% smaller binary, instant startup, lazy loading, and a stripped-down GPU-accelerated core.

05

WezTerm-Compatible Config

Use WezTerm’s Lua config directly with full API compatibility. No migration, no lock-in.

06

Polished Defaults

Copy on select, clickable file paths, history peek from full-screen apps, pane input broadcast, and a visual bell.

Built-in assistant

AI that lives in your terminal.

Not a chat widget bolted on — an assistant that understands the context of what you’re doing, right where you’re doing it.

01

Error recovery

When a command fails, MANDA automatically suggests a fix. Press Cmd+Shift+E to apply it.

02

Natural language to command

Type # describe the task at the prompt and MANDA injects the resulting command, ready for you to review and run.

03

Your provider, your rules

Configure Claude Code, Codex, Gemini CLI, Copilot CLI, and more — with one-click presets and full API-key or CLI-login auth.
