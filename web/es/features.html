Rápido por defecto. Tú decides cómo configurarlo.

Cada ajuste por defecto está pensado para un uso práctico desde el primer día, manteniendo un 100% de compatibilidad con la configuración Lua de WezTerm — trae tu config actual sin migrar nada.

01

Cero configuración

JetBrains Mono, renderizado tipográfico optimizado para macOS y tamaños de fuente ajustados de serie. Ábrelo y listo.

02

Experiencia consciente del tema

Cambia automáticamente entre modo oscuro y claro con macOS, con colores de selección ajustados, peso de fuente y overrides prácticos.

03

Suite de shell seleccionada

Plugins de zsh integrados con herramientas CLI opcionales para prompt, diff y navegación — configurados en el primer arranque.

04

Rápido y ligero

Binario un 40% más pequeño, arranque instantáneo, carga diferida y un núcleo GPU-acelerado depurado.

05

Config compatible con WezTerm

Usa la configuración Lua de WezTerm directamente con compatibilidad total de API. Sin migración, sin bloqueos.

06

Ajustes pulidos

Copiar al seleccionar, rutas de archivo clicables, vistazo al historial desde apps a pantalla completa, broadcast de entrada entre paneles y campana visual.

Asistente integrado

IA que vive en tu terminal.

No es un widget de chat pegado encima — es un asistente que entiende el contexto de lo que haces, justo donde lo haces.

01

Recuperación de errores

Cuando un comando falla, MANDA sugiere automáticamente una solución. Pulsa Cmd+Shift+E para aplicarla.

02

Del lenguaje natural al comando

Escribe # describe la tarea en el prompt y MANDA inyecta el comando resultante, listo para que lo revises y ejecutes.

03

Tu proveedor, tus reglas

Configura Claude Code, Codex, Gemini CLI, Copilot CLI y más — con ajustes de un clic y autenticación por API key o login CLI.
