FAQ

Respuestas, sin buscarlas.

Las preguntas que más surgen — plataformas, configuración, el asistente de IA, Homebrew y algunos detalles específicos de macOS. ¿No encuentras la tuya? Consulta el FAQ completo o abre un issue en GitHub.

¿Hay una versión para Windows o Linux?+

Por ahora no. MANDA es solo para macOS mientras se pule la experiencia en macOS. Windows y Linux pueden llegar más adelante.

¿Puedo usar una ventana transparente?+

Sí. Añade a ~/.config/manda/manda.lua:

local config = require("manda").config
config.window_background_opacity = 0.92
config.macos_window_background_blur = 20  -- desenfoque opcional, 0–100
return config
¿Cómo desactivo copiar al seleccionar?+ 
config.copy_on_select = false
¿Cómo personalizo los atajos de teclado?+

Añade a config.keys, no lo reemplaces:

config.keys[#config.keys + 1] = {
  key = "RightArrow",
  mods = "CMD|SHIFT",
  action = wezterm.action.ActivatePaneDirection("Right"),
}

Consulta keybindings.md y configuration.md para más ejemplos.

¿Puedo controlar la herencia del directorio de trabajo?+

Sí, individualmente para ventanas, pestañas y divisiones:

config.window_inherit_working_directory = true
config.tab_inherit_working_directory = true
config.split_pane_inherit_working_directory = true

Todas están activadas por defecto.

¿Cómo desactivo MANDA Assistant?+

Ejecuta manda ai, abre los ajustes de MANDA Assistant y pon Enabled en Off. O edita ~/.config/manda/assistant.toml directamente:

enabled = false
¿Cómo uso un proveedor de LLM personalizado?+

Ejecuta manda ai, mantén Auth Type en API key e introduce manualmente tu Base URL, API Key, Simple Model y Deep Model. Elige API Mode chat_completions para /v1/chat/completions, o responses para /v1/responses. Si el proveedor de Responses soporta búsqueda alojada, activa Native Web Search; no se necesita un proveedor de búsqueda ni una API key de búsqueda por separado.

¿Cómo restauro la configuración por defecto?+ 
manda reset

Esto elimina la integración de shell y tmux gestionada por MANDA, los valores por defecto de git delta gestionados, el estado de MANDA seleccionado y los bloques de tema gestionados en ~/.config/manda/manda.lua. El Lua escrito por el usuario fuera de los bloques gestionados se conserva. Ejecuta manda init de nuevo si quieres recuperar la integración de shell.

El comando manda no aparece. ¿Cómo lo recupero?+ 
/Applications/Manda.app/Contents/MacOS/manda init --update-only
exec zsh -l

Después ejecuta manda doctor para verificar que todo está en orden.

¿Cómo uso la CLI de MANDA desde scripts?+ 
manda cli split-pane
manda cli split-pane -- bash -c "echo hello"
manda cli --help

Consulta cli.md para la referencia completa.

¿Cómo activo la barra de desplazamiento?+

Abre manda config y alterna la opción de la barra de desplazamiento, o añade a ~/.config/manda/manda.lua:

config.enable_scroll_bar = true
¿Cómo me desplazo dentro de nano, vim u otra app de pantalla completa?+

Activa el reenvío de la rueda en la pantalla alterna:

config.alternate_screen_wheel_scrolls_terminal = true
¿Cómo cambio la fuente? Mi cambio de fuente no tiene efecto.+

Los cambios de fuente requieren establecer explícitamente config.font en tu configuración:

config.font = wezterm.font('Your Font Name')

Nota: el sistema de pesos de fuente consciente del tema de MANDA solo se aplica a la pila por defecto de JetBrains Mono. Una vez que pongas una fuente personalizada, MANDA ya no ajustará su peso automáticamente.

Mi cambio de window_padding no funciona.+

Los valores de window_padding requieren el sufijo de unidad 'px':

config.window_padding = { left = '24px', right = '24px', top = '40px', bottom = '20px' }

Los números simples (sin 'px') se interpretan como unidades de celda de terminal, que pueden no coincidir con lo que pretendes.

La pantalla salta arriba mientras Claude Code genera la salida.+

Es una interacción conocida entre el scroll del trackpad y la salida en streaming de Claude Code. Si haces scroll hasta arriba en mitad del stream, pulsar la flecha abajo o volver a bajar te devuelve a la salida actual. Se ha rastreado una corrección para el comportamiento de salto y se ha incluido en versiones recientes.

Cmd+Shift+Y envía una ruta local dentro de una sesión SSH.+

La función de archivos remotos de yazi (Cmd+Shift+R) está pensada para sesiones SSH y monta el sistema de archivos remoto vía sshfs. Cmd+Shift+Y es para yazi local. Usa Cmd+Shift+R cuando estés dentro de un panel SSH.

El wrapper de shell y no sincroniza mi directorio al salir.+

Asegúrate de que la integración de shell de MANDA para fish/zsh esté cargada. Compruébalo con manda doctor. El wrapper y requiere que el init del shell esté cargado. Una llamada simple a yazi no sincronizará el directorio.

Homebrew no encuentra el binario / se actualiza el MANDA equivocado.+

Hay un paquete antiguo sin relación llamado manda en Homebrew. Instala MANDA con el tap para evitar conflictos:

brew install WILFREDY-X/manda/manda

Si ves errores de checksum con manda update, usa brew upgrade WILFREDY-X/manda/manda directamente.

Las notificaciones de Claude Code no aparecen.+

Puede que el permiso de notificaciones de MANDA no esté concedido. Ve a Ajustes del Sistema > Notificaciones > MANDA y activa Permitir notificaciones. Después reinicia MANDA.

El atajo global no funciona en teclados no QWERTY (p. ej. Colemak).+

Cmd + Opt + Ctrl + K usa la posición física de la K en QWERTY. En Colemak corresponde a otra tecla. Remapéalo en tu configuración:

table.insert(config.keys, {
  key = 'k',  -- ajusta a la tecla física de tu distribución
  mods = 'CMD|OPT|CTRL',
  action = wezterm.action.EmitEvent('toggle-global-window'),
})
Los códigos QR y los gráficos de terminal se ven estirados en vertical.+

El valor por defecto line_height = 1.28 de MANDA favorece un espaciado de texto cómodo. Los gráficos de terminal construidos con caracteres — como códigos QR, logos de neofetch y barras TUI — escalan con la altura de fila, por lo que se renderizan un ~28% más altos que en terminales sin espaciado extra. Es una decisión tipográfica, no un bug de renderizado: los caracteres de bloque deben llenar toda la celda para que los bordes TUI y las barras de progreso se vean continuos.

Si quieres gráficos casi cuadrados, baja el line height en ~/.config/manda/manda.lua:

config.line_height = 1.1  -- o 1.0 para igualar terminales sin espaciado extra

Nota: ninguna terminal renderiza los códigos QR de medio bloque perfectamente cuadrados: con fuentes monoespaciadas comunes la celda es naturalmente un poco más alta que 2:1 incluso con line_height = 1.0.

¿Puedo usar MANDA con gestores de ventanas por tiles (yabai, AeroSpace)?+

MANDA es compatible con yabai y AeroSpace. Si ves parpadeos continuos, normalmente se debe a que el WM por tiles pelea con la lógica de pantalla completa/redimensionado de MANDA. Desactivar la pantalla completa nativa de MANDA (config.native_macos_fullscreen_mode = false) o excluir MANDA de la lista de ventanas gestionadas del WM por tiles suele resolverlo.
