FAQ

Respuestas, sin buscarlas.

Las seis preguntas que más surgen. ¿Falta algo? Abre un issue.

¿Hay una versión para Windows o Linux?+

Todavía no — por ahora solo macOS. Windows y Linux pueden llegar más adelante.

¿Cómo uso un proveedor de LLM personalizado?+

Ejecuta manda ai, mantén Auth Type = API key e introduce tu Base URL, API Key, Simple Model y Deep Model. API Mode: chat_completions para /v1/chat/completions, responses para /v1/responses. Si el proveedor soporta búsqueda alojada, activa Native Web Search — no hace falta una API key de búsqueda aparte.

¿Cómo personalizo los atajos de teclado?+

Añade a config.keys — no lo reemplaces:

config.keys[#config.keys + 1] = {
  key = "RightArrow",
  mods = "CMD|SHIFT",
  action = wezterm.action.ActivatePaneDirection("Right"),
}

Más ejemplos: keybindings.md · configuration.md

¿Cómo desactivo MANDA Assistant?+

Ejecuta manda ai → ajustes del asistente → Enabled: Off. O edita ~/.config/manda/assistant.toml:

enabled = false
¿Cómo restauro la configuración por defecto?+ 
manda reset

Elimina la integración de shell/tmux, los defaults de git delta, el estado y los bloques de tema gestionados por MANDA. Tu Lua se conserva. Ejecuta manda init para reinstalar la integración de shell.

Homebrew no encuentra el binario / actualiza el paquete equivocado.+

Hay un paquete antiguo sin relación llamado manda en Homebrew. Instala MANDA con el instalador de una línea:

curl -fsSL https://raw.githubusercontent.com/WILFREDY-X/manda/main/install/install.sh | bash
brew install WILFREDY-X/tap/manda
